Politique de Confidentialité - GRO-Tom Extension

Dernière mise à jour :

1. Collecte de données

Cette extension collecte uniquement :

  • Préférences utilisateur : Les paramètres d'activation/désactivation des modules sont stockés localement via chrome.storage.sync pour synchroniser vos préférences entre vos appareils.
  • IDs techniques en cache : Les identifiants techniques des colonnes Monday.com sont mis en cache localement (localStorage) pour améliorer les performances de recherche. Ces données sont stockées uniquement sur votre appareil.

2. Utilisation des données

  • Les données sont stockées uniquement localement sur votre appareil
  • Aucune donnée n'est transmise à des serveurs externes
  • Aucune donnée personnelle n'est collectée (nom, email, contenu des pages, etc.)
  • Les IDs techniques sont utilisés uniquement pour l'affichage dans l'interface et la fonctionnalité de recherche de l'extension
  • L'extension lit le contenu des pages Monday.com et Zapier.com uniquement pour extraire les identifiants techniques nécessaires à son fonctionnement

3. Partage de données

Aucune donnée n'est vendue, partagée ou transmise à des tiers.

L'extension fonctionne entièrement en local et ne communique avec aucun serveur externe.

4. Stockage des données

Toutes les données sont stockées localement sur votre appareil via :

  • chrome.storage.sync : Pour les préférences utilisateur (synchronisées entre vos appareils Chrome connectés au même compte)
  • localStorage : Pour le cache des IDs de colonnes (stockage local uniquement)

Vous pouvez supprimer toutes ces données à tout moment en désinstallant l'extension ou en utilisant la fonction "Clear" dans l'outil de recherche de colonnes.

5. Permissions

L'extension demande les permissions suivantes :

  • storage : Pour sauvegarder vos préférences et mettre en cache les IDs de colonnes
  • Accès aux domaines : Accès à *.monday.com et *.zapier.com pour injecter les scripts nécessaires à l'affichage des IDs techniques

6. Contact

Pour toute question concernant cette politique de confidentialité, veuillez contacter le développeur via le dépôt GitHub de l'extension.
